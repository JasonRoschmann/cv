# Startup protocol

Follow this sequence at the start of every session:

1. Read `CLAUDE.md` and imported project guidance.
2. Read project status markers if the repo maintains them.
3. Check memory status if memory is available.
4. Check for active P0/P1 bugs or broken validations.
5. Confirm readiness in this format:
   - guidance status
   - current completed work
   - work in progress
   - active bugs
   - recommended orchestration mode
   - next concrete step
6. Do not begin implementation before this startup snapshot is complete.
