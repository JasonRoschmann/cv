# Master analysis flow

1. Analyze the codebase without editing.
2. Classify findings by severity: P0, P1, P2, P3.
3. Propose orchestration strategy: single session, subagents, or agent team.
4. Fix one complete unit at a time.
5. After each fix, show code evidence and validation output.
6. Run live/browser QA where applicable.
7. Complete security, launch, and performance checklists before declaring launch readiness.
