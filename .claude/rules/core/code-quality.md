# Global code quality rules

- Solve the real problem, not just the visible symptom.
- Make the smallest complete change that resolves the issue.
- Keep behavior explicit; avoid clever implicit coupling.
- Reuse established local patterns unless there is strong evidence they are wrong.
- Remove dead branches or obsolete code introduced by the change.
- Do not leave placeholders, TODOs, or stubs unless the user explicitly asked for scaffolding.
- Before considering work done, confirm what was actually verified.
